# Benchmarks

Each post that runs benchmarks puts its scripts in this directory under a per-post folder (e.g. `benchmarks/post-01/`).

Raw outputs go to `benchmarks/results/post-N/` and are gitignored. Summary tables and key numbers cited in posts should be checked in as small markdown or JSON files.

**Rule:** every number cited in a published post must be reproducible from a script in this directory.
